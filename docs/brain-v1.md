# EchoMatrix Brain V1

Brain V1 consolidates the cognitive loop into one auditable record:

`market data -> quality -> market state -> research -> strategy -> AI council -> risk -> allocation -> simulation -> outcome -> learning -> durable memory`

## Evidence layer
Each cycle records stage, summary, inputs, and confidence. The cycle also records a deterministic cycle ID, controls, simulation outcome, learning update, and durable-memory checksum.

## Decision attribution
The cycle exposes the conclusion, primary evidence drivers, risk constraint, capital constraint, and simulated result.

## Research gate
The Brain V1 scorecard evaluates simulation completion, simulation-only boundary, OOS evidence, stress evidence, Monte Carlo evidence, bounded drawdown, and provider reliability.

Gates: `READY FOR MORE RESEARCH`, `WEAK EVIDENCE`, `FAILED VALIDATION`.

The gate is a research-quality signal, not permission for live financial execution.
